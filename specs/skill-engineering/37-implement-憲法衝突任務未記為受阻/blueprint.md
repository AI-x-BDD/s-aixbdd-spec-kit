### 工作項內容

#### W2：Rule 2 改寫

- 標題改為「只有環境限制與憲法衝突可以記為受阻，且不得假裝完成」。
- 第 2 條改為：可以記為受阻的原因只有兩種：
  - 環境限制：外部服務無法啟動、套件或映像無法下載、缺少權限、憑證或硬體，導致任務無法完成。
  - 憲法衝突：任務要求和「憲法檢查清單」的「必須」或「不得」規則無法同時滿足，例如任務描述要求「不得」規則禁止的套件、設定或做法，或照任務描述實作就無法符合「必須」規則。
- 新增條列：憲法衝突不屬於 Rule 1 的文件矛盾，不得依權威順序自行決定採用憲法或任務描述，也不需要嘗試替代做法。
- 新增條列：不得刪除、略過或改寫任務要求中和憲法衝突的部分，再以其餘部分完成並打勾。
- 第 1 條（3 輪未通過先找根因並嘗試替代做法）改為只適用環境限制；其餘條列（程式錯誤不得受阻、受阻不得打勾、連帶受阻、不得假實作）原文不變，適用兩種原因。
- 原 Good／Bad Example 改為 Example 1；新增 Example 2，使用診所掛號情境，不使用 Prettier、ESLint 或 1A2B：
  - Good：憲法 `code.md` Rule 3「不得使用 moment.js」，T006 要求安裝 `moment` 並建立日期工具；T006 記為受阻並寫出 `code.md` Rule 3，直接使用該日期工具的 T012 一併受阻，其餘任務照常執行。
  - Bad：同一情境把 `moment` 換成其他套件或刪掉後，以其餘部分完成 T006 並打勾，把衝突寫進「憲法偏離」。

#### W3：Rule 3 改寫

- 「受阻也必須記入決策紀錄，理由必須寫出根因與已嘗試的替代做法」改為：受阻也必須記入決策紀錄；環境受阻的理由必須寫出根因與已嘗試的替代做法，憲法衝突受阻的理由必須寫出衝突的憲法檔路徑與 Rule 編號。
- 範例不變。
