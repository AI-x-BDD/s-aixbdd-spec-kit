# Rule 1 - 缺口類型只用四種並依上游文件是否一致區分

- 缺口類型必須是缺少、部分、矛盾、未要求其中之一。
- 缺少：沒有任何對應的程式。
- 部分：有程式，但部分條件、情境或狀態沒有做到。程式和某份上游文件不同、但上游文件之間一致時，必須判為部分。
- 矛盾：只在上游文件之間寫法不同時使用；程式與文件的差異不得因此判為矛盾。
- 未要求：程式有任何需求與任務都沒有要求的行為。

## Good Example

- 上游文件之間一致，只有程式沒有做到，類型為部分。

情境：

- `contracts/openapi.yaml` 的設備清單端點有 `sort` 參數，`ui/plan.md` 的清單畫面有「依借出日排序」控制項，兩者一致。
- 程式的清單畫面沒有排序控制項，也沒有傳送 `sort` 參數。
- 缺口類型：部分。

## Bad Example

- 同一情境把程式與文件的差異寫成矛盾；API 合約與 UI 規劃並沒有互相衝突。

情境：

- 缺口類型：矛盾。
- 說明：清單畫面沒有排序控制項，和 `ui/plan.md` 矛盾。

# Rule 2 - 嚴重度依影響判定

- 嚴重度必須是 CRITICAL、HIGH、MEDIUM、LOW 其中之一。
- 違反憲法「必須」或「不得」規則的缺口，必須判為 CRITICAL。
- 某個 User Story 完全無法完成的缺口，必須判為 CRITICAL。
- 需求只做到一部分，使用者在某些條件下拿不到需求要求的結果時，必須判為 HIGH。
- 文件之間矛盾，或程式和某份文件不同，但需求的功能可以完成時，必須判為 MEDIUM。
- 文字、訊息用語、測試或驗證方式的差異，必須判為 LOW。

## Good Example

- 程式違反憲法的「不得」規則，一律判為 CRITICAL，不論功能是否可以完成。

情境：

- `.agents/constitution/skills/implement/code.md` 的 Rule 3 規定程式碼不得輸出使用者的電子郵件到日誌。
- 借出服務在 `src/services/loan.ts:58` 以 `console.log` 輸出借用人的電子郵件。
- 嚴重度：CRITICAL。

## Bad Example

- 只是按鈕用語和雛形不同，功能可以完成，卻判為 HIGH。

情境：

- `ui/loan-form.html:31` 的按鈕文字是「送出」，`src/views/LoanForm.tsx:64` 的按鈕文字是「提交」。
- 嚴重度：HIGH。

# Rule 3 - 處理只寫附加任務或上游缺口

- 處理必須是「附加任務」或「上游缺口：<Skill>」；不得寫「不處理」。
- 上游文件已定義預期行為、只剩程式工作時，處理必須寫「附加任務」。
- 完成缺口需要上游沒有定義的設計或決定時，處理必須寫負責該設計的 Skill。
- 上游文件互相矛盾時，處理必須寫程式沒有遵循那一方的 Skill，剩餘工作必須寫明程式遵循哪一方。
- 類型為未要求的缺口，處理必須寫「上游缺口：`s-specify`」。

## Good Example

- 程式遵循 API 合約，資料模型的欄位名稱不同；處理指名程式沒有遵循的資料模型所屬的 Skill。

情境：

- `contracts/openapi.yaml` 的借用紀錄欄位是 `dueDate`，`data/data-model.dbml` 的欄位是 `due_at`，程式回傳 `dueDate`。
- 處理：上游缺口：`data-plan`。
- 剩餘工作：程式照 API 合約，由 `data-plan` 修正資料模型的欄位名稱。

## Bad Example

- 同一情境寫成附加任務，要求改程式配合資料模型；程式已遵循 API 合約，這會讓程式和 API 合約不同。

情境：

- 處理：附加任務。
- 剩餘工作：把回傳欄位改為 `due_at`。

# Rule 4 - 證據必須可定位

- 程式證據必須寫 `路徑:行號` 或 `路徑:起-迄`，該行必須存在且內容支持描述。
- 文件證據必須寫行號，或 § 段落、需求編號等可定位的標記。
- 缺口類型為矛盾時，必須列出雙方的位置。
- 任務的勾選狀態不得當成證據。

## Good Example

- 程式證據附起迄行號，文件證據附 § 段落，讀者可以直接核對。

情境：

- 證據：`src/services/loan.ts:42-47` 只檢查借用期限的上限，沒有檢查下限；`plan.md` §3 規定期限必須介於 1 到 14 天。

## Bad Example

- 用勾選狀態當證據，或只寫檔名沒有行號，讀者無法核對。

情境：

- 證據：T021 已勾選，程式已完成。
- 證據：`src/services/loan.ts` 沒有檢查期限下限。
