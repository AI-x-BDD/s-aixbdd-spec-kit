# Rule 1 - 節收穫必須完整且附來源

- 每節值得保留的觀念、理由、例子、前提及限制必須保存並附來源位置；來源沒有該項時必須明示，不能補成課程原文。
- 不得以固定數量上限或單篇文章主題刪去未採用收穫。
- 來源缺時間碼時必須使用檔案版本、段落標題與可定位短句；只保存必要定位，不自動複製付費教材全文。

## Good Example

- 自製情境保留可核對依據與限制。

- 書目第1節保留同名需比作者與缺作者暫緩兩項，附原段定位；沒有例子時寫來源未提供。

## Bad Example

- 相同情境遺漏依據或超出可支持的結論。

- 只因文章選同名比較就丟掉缺作者限制，另編一個案例冒充課程原文。

# Rule 2 - 跨節比較必須保留穩定ID與來源鏈

- 每次必須比較新增、重複或修正，保留舊來源及目前採用說法；未讀內容不得由節名推知。
- 收穫ID必須從既有最大數字接續，既有ID不得隨章節或文章排序更換。
- 同版本重送必須核對既有項目並保存來源別名及重複關係；來源修訂必須另存收穫版本，連回受影響文章及確認。

## Good Example

- 自製情境保留可核對依據與限制。

- H001保留同名比作者；新版補版本欄時另存harvest-v2並連回v1及受影響大綱，未提供第2節仍標未讀。

## Bad Example

- 相同情境遺漏依據或超出可支持的結論。

- 重送就建立新H002，覆寫舊說法，依第二節標題推測其全部內容。

# Rule 3 - 成文建議必須有內容價值依據

- 必須依已讀內容及其可教成果提出獨立成文、合併或暫存的建議與理由；不得只按節名或一節一篇定篇數。
- 暫存必須保留收穫及可觀察的再評估條件；研究尚未完成的候選必須標出研究待定。

## Good Example

- 自製情境保留可核對依據與限制。

- 同名書與版本判斷需合併才有完整準則；缺版本例時先暫存，收到該例再評估。

## Bad Example

- 相同情境遺漏依據或超出可支持的結論。

- 只因有兩節，就決定各寫一篇，刪掉未成文收穫。

# Rule 4 - 章級整合必須有跨節新增價值

- 章級建議必須指出跨節關係、使用順序或整體判斷的新增價值及來源。
- 只有重述時必須如實建議保留收穫；資料未齊時必須明列已讀範圍與未讀限制。

## Good Example

- 自製情境保留可核對依據與限制。

- 作者比對與版本比對合成「先辨作品再辨版本」順序，連回兩節；第三節重述不增加文章。

## Bad Example

- 相同情境遺漏依據或超出可支持的結論。

- 章名有「完整指南」就宣稱整章已讀，每章固定新增全貌篇。
